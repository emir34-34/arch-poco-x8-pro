# Arayüz konsepti v1 — "Akış" (taslak, kullanıcı değerlendirecek)

Ana fikir: telefon bir "zaman akışı". Ana ekran uygulama ızgarası değil, dikey bir
şerit: ortada ŞİMDİ, yukarı kaydırınca GELECEK, aşağı kaydırınca GEÇMİŞ.

1. Ana ekran = Akış
   - Ortada "Şimdi" kartı: saat, hava, çalan müzik, devam eden arama, şarj.
   - Yukarısı Gelecek: alarmlar, takvim, hatırlatıcılar, yarının havası.
   - Aşağısı Geçmiş: bildirimler, son açılan uygulamalar, son fotoğraflar, mesajlar —
     zamana göre tek şeritte. (BlackBerry Hub fikri + WP canlı yüzey)
2. Başparmak yelpazesi (uygulama açıcı)
   - Alt köşeden başparmakla çekince yay şeklinde açılan yelpaze; kaydırınca
     uygulamalar yay üstünde döner, harfe atlamak için dış halka. Tek elle.
     Sol/sağ el ayarı. (yeni; WP alfabe atlama + iPod çark hissi)
3. Nabız (kamera deliği çevresi)
   - Kamera deliğinin etrafında canlı ince halka/hap: arama süresi, müzik dalgası,
     şarj yüzdesi, indirme ilerlemesi. Dokununca açılır. (iOS Dynamic Island fikri)
4. Kart destesi (uygulama geçişi)
   - Alttan yukarı kaydırınca uygulamalar destelenmiş kartlar; kartı yukarı fırlat =
     kapat; aynı uygulamadan pencereler üst üste. (webOS kartları)
5. Kenar hareketleri, düğme yok
   - Soldan kenar = geri, sağdan kenar = akışa göz at (uygulamayı bırakmadan
     yarım çekip bildirimlere bak, bırakınca geri dön — BB10 "peek").
   - Uygulamada aşağı çekip tut = menü (Sailfish "pulley").
5b. Hızlı ayarlar: üstten çekince büyük döşemeler (Wi-Fi, ses, ışık…),
    basılı tutunca ayar sayfası. (Android)
6. Görsel dil
   - Büyük, cesur tipografi (WP'den), ama düz değil: hafif cam/derinlik katmanları,
     fiziksel yaylı animasyonlar (iOS).
   - Tek vurgu rengi, duvar kağıdından otomatik (Material You fikri).
   - Koyu tema varsayılan (OLED, pil).
7. Klee'ye özel
   - Arka RGB ışık bildirimleri yansıtır: kim aradıysa onun rengi, şarj dolumu dalga.
   - Ters koyunca sessiz + arka ışık "nefes alır".
   - Türkçe öncelikli.
